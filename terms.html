本利用規約（以下「本規約」といいます。）は、株式会社アルバト（以下「当社」といいます。）が提供するアプリケーション「トワネ」（以下「本アプリ」といいます。）の利用条件を定めるものです。利用者（以下「ユーザー」といいます。）は、本規約に同意のうえ本アプリを利用するものとします。

本アプリのキャラクターは実在しません。応答はAIが自動的に生成した創作であり、事実の記述ではありません。相手が人間であるかのように感じられることがありますが、人間ではありません。詳細は第5条をご確認ください。

第1条（適用）

本規約は、本アプリの利用に関する当社とユーザーとの間の一切の関係に適用されます。当社が本アプリ内またはウェブサイト上で掲示する個別の規定・ガイドラインは、本規約の一部を構成します。

第2条（定義）

  • キャラクター：本アプリ上でAIが演じる架空の人物その他の存在をいいます。当社が用意したものと、ユーザーが作成したものがあります。
  • 生成コンテンツ：ユーザーの入力に応じてAIが生成した文章、画像その他の情報をいいます。
  • ユーザーコンテンツ：ユーザーが本アプリに入力・作成・公開した情報（メッセージ、キャラクターの設定、ニックネーム等）をいいます。
  • コイン：本アプリ内の機能を利用するために消費する、本アプリ内でのみ使用できる数値をいいます。
  • トワネパス：当社が提供する定期購読（自動更新サブスクリプション）をいいます。

第3条（アカウント）

  1. 本アプリの利用にはアカウントの登録が必要です。ユーザーは、登録にあたり真実かつ正確な情報を提供するものとします。
  2. 13歳未満の方は本アプリを利用できません。
  3. 未成年の方は、あらかじめ法定代理人（保護者）の同意を得たうえで本アプリを利用するものとします。アプリ内課金を行う場合も同様です。
  4. アカウントの管理はユーザーの責任において行うものとし、第三者に利用させてはなりません。

第4条（利用）

ユーザーは、本規約および関連法令を遵守し、自己の責任において本アプリを利用するものとします。本アプリの利用に必要な通信環境および通信料はユーザーの負担とします。

第5条（AIによる生成コンテンツ）

  1. 本アプリのキャラクターおよびその応答はすべて架空の創作であり、実在の人物、団体、事件等とは関係ありません。
  2. 生成コンテンツは、AIが確率的に文章を組み立てたものです。当社は、その正確性、真実性、完全性、有用性、および特定の目的への適合性を保証しません。事実と異なる内容が生成されることがあります。
  3. 生成コンテンツは当社の見解を表明するものではありません。
  4. ユーザーは、生成コンテンツを、医療、健康、法律、税務、投資その他の専門的な助言として利用してはなりません。また、生命・身体・財産に関わる判断の根拠として利用してはなりません。これらについては必ず有資格の専門家にご相談ください。
  5. 同一の入力に対しても、生成される内容は都度異なります。特定の応答が再現されることを当社は保証しません。
  6. ユーザーが生成コンテンツを本アプリの外部で利用する場合、その利用について生じる責任はユーザーが負うものとします。

第6条（禁止事項）

ユーザーは、本アプリの利用にあたり、以下の行為をしてはなりません。ユーザーコンテンツの作成・公開、およびキャラクターへの入力においても同様です。

1. 性的な表現

  • 性的行為、性器または裸体を描写する内容（文章・画像を問いません）
  • 未成年またはそのように見える者を性的に描写する内容（いかなる態様であっても絶対に禁止します）

2. 権利の侵害

  • 実在の人物または実在のキャラクターになりすます内容、およびこれらを想起させる名称・設定を用いる行為
  • 当社または第三者の著作権、商標権、肖像権、パブリシティ権、プライバシー、名誉その他の権利・利益を侵害する行為
  • 他人の個人情報を、本人の同意なく入力または公開する行為

3. 有害な内容

  • 過度に暴力的な内容、自傷・自殺・摂食障害等を助長し、または推奨する内容
  • 人種、民族、国籍、信条、性別、性的指向、障害等を理由とする差別または憎悪をあおる内容
  • 犯罪行為を助長し、または違法な薬物・武器等の取引に関連する内容

4. その他

  • 法令または公序良俗に違反する行為
  • 本アプリの運営を妨害するおそれのある行為、リバースエンジニアリング、不正アクセス、自動化された手段による大量のアクセス
  • コインその他の本アプリ内の権利を、当社の認めない方法で第三者に譲渡し、または換金する行為
  • 安全のための仕組み（モデレーション等）を回避しようとする行為
  • その他、当社が不適切と合理的に判断する行為

  1. ユーザーコンテンツの権利は、当該ユーザーに帰属します。ユーザーは、ユーザーコンテンツについて自らが必要な権利を有していること、および第三者の権利を侵害しないことを保証するものとします。
  2. ユーザーは当社に対し、本アプリの提供・維持・改善および安全確保に必要な範囲で、ユーザーコンテンツを無償で使用（複製、保存、送信、表示、翻案を含みます）する権利を許諾するものとします。ユーザーがキャラクターを公開した場合、当該キャラクターを他のユーザーが本アプリ内で利用できるようにするために必要な範囲を含みます。
  3. 当社は、ユーザーコンテンツを、本アプリ以外のサービスの宣伝広告に、ユーザーの同意なく利用しません。

第8条（通報・監視・措置）

  1. 本アプリは、公開されたキャラクター、投稿およびメッセージについて、通報機能とブロック機能を提供します。
  2. 当社は、投稿の前後を問わず、ユーザーコンテンツおよび生成コンテンツについて自動的な検査を行うことがあります。
  3. 当社は、通報を受け付けてから24時間以内に内容を確認し、必要な措置を講じます。
  4. 当社は、本規約に違反し、または違反するおそれがあると判断した場合、事前の通知なく、次の措置を講じることができます。
    • ユーザーコンテンツの非公開化または削除
    • 本アプリの利用の一時停止、アカウントの停止または削除
  5. 前項の措置により、ユーザーが保有していたコインおよびトワネパスの残存期間について、当社は払戻しその他の補償を行いません。ただし、当社の責めに帰すべき事由による場合はこの限りではありません。

第9条（コイン）

  1. コインは、イラストの生成、より長い応答の利用その他、本アプリが定める機能を利用するために消費します。
  2. コインは、購入（有償）のほか、ログインボーナス、広告の視聴、トワネパスの特典等（無償）により取得できます。
  3. コインには有効期限があります。取得の方法により、期限は次のとおりです。
    購入（有償）により取得したコイン取得の日から170日
    トワネパスの特典として配布されるコイン取得の日から60日
    ログインボーナス・広告の視聴等（無償）により取得したコイン取得の日から170日
  4. コインは、有効期限の近いものから順に消費されます。
  5. 有効期限を経過した未使用のコインは失効します。失効したコインの復活および払戻しは行いません。
  6. コインは、法定通貨その他の財産的価値と交換することはできず、払戻しを行いません。また、第三者への譲渡、貸与および相続はできません。
  7. アカウントを削除した場合、保有していたコインは消滅します。払戻しは行いません。
  8. 当社が本アプリの提供を終了する場合の未使用のコインの取扱いは、法令に従い、あらかじめ本アプリ内で告知します。

第10条（アプリ内課金・トワネパス）

  1. 本アプリには、コインの購入（消費型）およびトワネパス（自動更新サブスクリプション）が含まれます。
  2. 課金の決済および返金は、App Store（Apple Inc.）またはGoogle Play（Google LLC）の定める条件に従います。返金の可否は各プラットフォームが判断するものであり、当社が直接返金することはできません。
  3. トワネパスは、解約の手続きがなされない限り、各プラットフォームの定めに従い自動的に更新されます。解約は、更新日の24時間前までに、各プラットフォームの購読管理画面から行ってください。アプリの削除では解約されません。
  4. 当社は、トワネパスの内容および特典を変更することがあります。ユーザーに不利益となる重要な変更を行う場合は、あらかじめ本アプリ内で告知します。
  5. 詳細は特定商取引法に基づく表記をご確認ください。

第11条（広告）

本アプリには第三者配信の広告が表示されます。広告主のサービスやウェブサイトの内容について、当社は責任を負いません。トワネパスにご加入の間は、広告を表示しません。

当社は、本アプリの内容を変更し、または提供を停止・終了することができます。ユーザーに重大な影響を及ぼす変更または提供の終了を行う場合は、あらかじめ相当な期間をおいて本アプリ内で告知します。ただし、緊急を要する場合はこの限りではありません。

第14条（規約の変更）

当社は、本規約を変更することがあります。変更が、ユーザーの一般の利益に適合する場合、または契約の目的に反せず合理的なものである場合は、変更後の本規約は本ページに掲載した時点から効力を生じます。ユーザーに不利益となる重要な変更を行う場合は、効力発生日を定めたうえで、あらかじめ本アプリ内で告知します。
