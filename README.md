## 2026-11-20 の書き直し（ブランチ `mellows-rewrite`）

トワネを「ポイ活×AIキャラチャット・18歳以上だけ」に作り変えるのに合わせて、全ページを書き直した。
仕様の正は設計書（`ai-character-app/docs/01〜07`）。**main に入れるのはオーナーの確認後。**

- 公開リポジトリなので、HTML コメントに社内メモ（要確認・下書き・変更の説明）を書かない。確認待ちの点は towane（非公開）の `docs/legal-open-questions.md` に書く
- 「（未確定）」と書いた項目（読み上げ・通話の事業者、中国系の事業者の国、分析の事業者）は、決まったら直す
- 以前の版（13歳以上・コイン・トワネパス・OpenAI）は main の履歴に残る

## 2026-11-21 の年齢の方針の変更（ブランチ `mellows-rewrite`）

- 「18歳以上だけ」をやめた。13歳未満は利用不可（仮置き）、未成年は保護者の同意、App Store の区分は 18+ のまま
- 18歳以上だけの機能（アンリミテッド・肌を見せる写真/動画・一部の公式キャラ）、生年月日の自己申告（訂正は30日に1回）、
  未成年の月の購入上限（16歳未満 5,000円／16・17歳 20,000円）と購入ごとの保護者同意、18歳未満は非パーソナライズ広告
- 上限の金額・訂正の間隔は `terms.html` 第12条・第3条、`tokushoho.html`、本体の設定値を揃える
- AI の送信先から Google（Gemini）を外し、OpenRouter・DeepInfra・OpenAI・xAI にした（`privacy.html` 4.）

## 原本について

以前は「原本は本体リポジトリの `docs/*.html`、ここは配置するだけ」だった。
**今回の書き直しはこのリポジトリで行った**（本体は作り変えの作業中のため）。
本体の `docs/terms.html`・`privacy.html`・`tokushoho.html` は以前の版のままなので、
公開するときに、本体の側を消すか、ここから写して揃える。揃えないまま本体からコピーすると、以前の版で上書きされる。

アプリからのリンクは本体の `src/lib/legal.ts` の `LEGAL_URLS`。**ファイル名を変えない**こと
（審査に出したあとにリンク切れになる）。

## 内容を変えるときの注意

- 利用規約・プライバシーポリシーの本文を変えたら、本体の同意の版（設定値 `consentVersion`）を上げる。
  上げると既存ユーザーに再同意を求める
- AI 事業者を足す・替えるときは、プライバシーポリシーの改定と同意の取り直しを同じ公開に入れる（設計書 05 §6）
- 価格とポイント数はページに書いていない（購入画面の表示に従う）。
  **無償ポイントの有効期限（180日）は `terms.html`・`tokushoho.html` と本体の設定値の3箇所が揃っているか**を確認する
- 有償ポイントに期限を付けない・有償と無償を分けて持つ、は `terms.html`・`funds.html` と台帳の実装が揃っていること
- 運営者の表記に個人名を書かない
- **特商法の「運営統括責任者」と電話番号は、「請求により遅滞なく開示」で省略している**（2026-11-20 に決めた）。
  法令上、省略できる：特定商取引法 第11条ただし書。消費者庁「特定商取引法ガイド」の通信販売のページの表で、
  「販売業者の氏名（名称）、住所、電話番号」「法人の代表者名・責任者名」はどちらも「省略できる」
  （https://www.no-trouble.caa.go.jp/what/mailorder/ 、通信販売広告Q&A の Q15・Q17。2026-11-20 閲覧）。
  条件は2つ：(1) 請求があれば書面か電子メールで遅滞なく提供する、とページに表示する（`tokushoho.html` の「※ 開示の請求」）、
  (2) **実際に請求が来たら遅滞なく返せるようにしておく**（`info@albato-inc.com` に届いた請求に、責任者の氏名と
  連絡の取れる電話番号を書いたメールを返す。返信の文面を用意しておく）。(2) ができていないと、省略は認められない。
  返品に関する事項・メールアドレス・動作環境は省略できないので、ページに書いてある
- `delete-account.html` は、本体の退会の実装（`functions/src/account/delete-account.ts`）と `privacy.html` の 3.・9. に
  合わせてある。退会で消すもの・残すものを実装で変えたら、3つを一緒に直す。
  「アプリを使えない場合はメールで依頼 → 7日以内に当社で削除」と書いたので、**運営が uid を指定して退会の処理を流す手順**
  （本体の `scripts/ops`）が要る（2026-11-20 時点では無い）

## 2026-11-24 の Web 版の追記（ブランチ `web-version`）

Web 版（トワネのブラウザ版）の提供に合わせて、規約・ポリシー・表示を足した。設計書は towane（非公開）の `docs/web-design.md` §6・`docs/web-billing.md` §6。
**main に入れるのはオーナーの確認後。**

- 画面上で目立つ `【要記入】`・`【決定待ち】`・`【要確認】`（黄色の印）が残っている。公開の前に `grep -rn 'class="todo"' *.html` で全部消えていることを確かめる
- **アプリから開くページ（`terms.html`・`privacy.html`・`funds.html`・`tokushoho.html`・`delete-account.html`）には、Web 版の購入の条項・決済手段・値段・購入ページへのリンクを書かない**（Apple 3.1.1。2026-11-24 のオーナー決定）。Web の購入の条項（決済代行・カード情報を持たない・最終確認・返品不可と例外・決済取消しでのポイント取消し・不正決済への措置）は `terms-web.html`、支払い方法・カードの扱いは `tokushoho-web.html` にだけ書く。この2ページは `noindex` で、アプリと他のページからリンクしない（2ページの間と、2ページから他の規約へのリンクは可）
- `terms.html` には「Web 版には Web版 追加規約が適用される」とだけ書く（リンクなし）。`privacy.html` には決済代行事業者（GMOイプシロン）と reCAPTCHA を、Web 版の利用者にだけ関わる提供先として残す（値段・購入ページは書かない）
- 同意の版（`consentVersion`）は上げない（2026-11-24 のオーナー決定）。Web 版の登録画面で、そのときの最新版（`terms.html`・`privacy.html`・`terms-web.html`）への同意を取る前提
- アプリ用の `tokushoho.html` は変えていない（請求により開示の方式のまま）
- `tokushoho-web.html` の運営統括責任者（代表取締役の氏名）・電話番号（トワネ専用の050番号）は、`tokushoho.html` と違い**省略せず書く**（fincode の審査の見本が明記を求めるため）。実際の氏名・番号が決まったら、オーナーの了承を得て入れる（上の「運営者の表記に個人名を書かない」の例外になる。弁護士に確かめる）

### 公開前の確認

1. `grep -rn 'class="todo"' *.html` が 0 件
2. アプリから開くページに購入の記述が無い：`grep -n 'terms-web\|tokushoho-web\|fincode\|Web版での購入\|Web版で購入' terms.html privacy.html funds.html tokushoho.html delete-account.html index.html` で、購入への案内（リンク・値段・支払い手段）が出ないこと（privacy の GMOイプシロン・reCAPTCHA の行は可）
3. 閉じタグの対応：正規表現で数える（各ページで `table` `tr` `td` `th` `ol` `ul` `li` `h2` `p` `div` `main` `mark` の開きと閉じの数が一致）
4. `terms-web.html`・`tokushoho-web.html` が `noindex,nofollow` で、`terms-web` へのリンクが `tokushoho-web.html`・`terms-web.html` 以外に無いこと
